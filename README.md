# wuwa-match3-bot

鳴潮「無音消除」三消活動的自動遊玩腳本。全程在本機運行：讀圖用本機顯卡做顏色閾值運算，決策用固定規則的代碼，不連網，也不使用任何 AI 模型或服務。PyTorch 在這裏只作為顯卡運算庫，沒有載入模型。

## 使用

1. 遊戲 client 區域設為 1280x720。
2. 雙擊 `run.bat`，在 UAC 提示按「是」（遊戲以系統管理員權限運行，滑鼠輸入也需要同等權限）。
3. 切回遊戲，自己揀關卡。

棋盤一出現就自動開打，打完回到等待狀態，下一關同樣自動開始。切走遊戲視窗時會暫停，切回來繼續。按 F8 結束。

只想看它會怎麼走、不實際操作：

```bash
python bot.py --dry
```

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `run.bat` | 雙擊啟動 |
| `bot.py` | 主循環：等待關卡、讀盤、出手 |
| `win.py` | 尋找遊戲視窗 |
| `capture.py` | PrintWindow 截圖 |
| `vision.py` | 在顯卡上辨識 8x7 棋盤與特殊棋，並判斷是否在關卡內 |
| `solver.py` | 模擬交換與連鎖，選分數最高的一步 |
| `inputs.py` | SendInput 滑鼠拖動 |
| `test_vision.py` | 用存檔畫面離線檢查辨識 |

## 已實測的遊戲行為

- 能量瓶會隨棋子下落；瓶子被消除後，遊戲會把棋盤上現有棋子變成新瓶子。
- 連鎖結算期間的拖動會被遊戲忽略，而連鎖中途的停頓看起來像棋盤已靜止，所以每步都等回合數字跳動才走下一步。
